# Student Management System

## Introduction

MongoDB is a popular NoSQL database management system that stores data in the form of documents.

This project is a Student Management System developed using MongoDB. The database contains student records, and various operations have been performed on the student data, such as inserting, displaying, updating, and deleting records. Sorting and filtering operations have also been demonstrated.

## Objectives

- To understand the concept of NoSQL databases.
- To learn the basic features of MongoDB.
- To create a database and collection.
- To insert 30 student records.
- To perform CRUD operations.
- To use comparison operators.
- To perform sorting and filtering.
- To understand AND and OR operations.

## Technologies Used

- MongoDB
- MongoDB Compass / MongoDB Shell

## Database Details

The project uses MongoDB to store and manage student information. A database and collection are created to store the student records.

The collection contains 30 student records on which different MongoDB operations are performed.

## Operations Performed

### 1. Create Database and Collection

A MongoDB database and collection are created for storing student information.

### 2. Insert Records

30 student records are inserted into the collection using MongoDB commands.

### 3. CRUD Operations

CRUD operations are performed on the student data:

- **Create** – Insert student records.
- **Read** – Display student records.
- **Update** – Modify existing student information.
- **Delete** – Remove student records.

### 4. Comparison Operators

Comparison operators are used to compare values in student records.

Examples:

- `$eq` – Equal to
- `$ne` – Not equal to
- `$gt` – Greater than
- `$gte` – Greater than or equal to
- `$lt` – Less than
- `$lte` – Less than or equal to

### 5. Sorting

Sorting operations are performed to arrange student records in ascending or descending order based on a particular field.

### 6. Filtering

Filtering is used to display only those student records that satisfy a particular condition.

### 7. AND Operation

The `$and` operator is used when multiple conditions must be satisfied at the same time.

### 8. OR Operation

The `$or` operator is used when at least one of multiple conditions needs to be satisfied.

## Conclusion

The Student Management System demonstrates the basic concepts and features of MongoDB. Through this project, CRUD operations, comparison operators, sorting, filtering, AND, and OR operations are performed on student records.

This project helped in understanding how MongoDB can be used to store, manage, and retrieve data using a NoSQL database.
